# QuantPG-Platform 量化金融数据平台
基于 PostgreSQL + Python 搭建的 A 股量化行情数据全流程平台，实现**数据采集 → ETL 入库 → 数据清洗 → 质量校验 → 金融指标计算 → 数据库优化 → 安全加固**工业级全流程闭环。

## 项目目录结构
QuantPG-Platform/
├── etl/                # 数据ETL入库脚本
├── data/               # 原始数据/清洗后数据文件夹（Git不上传）
├── sql/                # 建表SQL、数据校验SQL、金融指标计算SQL
├── .env                # 数据库隐私配置文件（Git不上传）
├── .gitignore          # Git上传过滤规则（屏蔽敏感文件/数据文件）
└── README.md           # 项目说明文档

## 技术栈
- 数据库：PostgreSQL 14+
- 开发语言：Python 3.9+
- 数据处理：Pandas、SQLAlchemy
- 工程规范：.env 环境变量、数据脱敏、Git安全过滤
- 核心场景：金融时序数据处理、量化策略底层数据支撑

## 核心功能
1. **量化数据库设计**：自主设计6张核心表，覆盖股票基础信息、日线行情、交易账户、股票订单、量化策略、回测结果全业务场景
2. **ETL数据入库**：Python自动化脚本实现CSV数据清洗、去重、批量入库PostgreSQL
3. **数据质量校验**：重复数据检测、日期断档检测、异常价格检测、跨表一致性校验
4. **金融指标计算**：MA5/MA10/MA20均线、日收益率、累计收益率、滚动波动率
5. **性能优化**：时序数据联合索引，提升高频查询效率
6. **安全规范**：敏感配置环境变量隔离，杜绝密码泄露，符合开源标准

## 使用流程
1. 执行 `sql/` 目录下的建表SQL，初始化数据库表结构
2. 在项目根目录配置 `.env` 文件，填写PostgreSQL连接信息
3. 将清洗后的行情数据放入 `data/` 文件夹
4. 运行 `etl/import_stock.py` 完成数据批量入库
5. 执行SQL目录下的脚本，完成数据校验与指标计算
6. 验证数据入库结果，完成全流程测试
